      ❓ Comment utiliser l'application

      1. Préparer la partie

      1. Clique sur Créer le salon : un code et un QR code s'affichent.
      2. Ouvre l'écran secondaire (projecteur) avec le bouton dédié et place-le sur la TV / le vidéoprojecteur. Clique dessus une fois pour activer le son.
      3. Les joueurs scannent le QR code (ou saisissent le code) sur leur téléphone et entrent leur prénom.
      4. Choisis les rôles en jeu (le nombre doit correspondre au nombre de joueurs) puis clique sur Distribuer les rôles.
      5. Chaque joueur découvre son rôle sur son téléphone. La partie ne peut commencer que lorsque tous ont pris connaissance de leur rôle.

      2. Dérouler la partie

      Utilise les boutons 🌙 Phases du Jeu / 🎭 Appels des Personnages dans l'ordre : Maire, Nuit tombante, Voleur, Cupidon, Voyante, Renard, Loups-garous, Sorcière, puis Le Jour se lève. Un bandeau t'indique le prochain rôle à appeler.

      • Maire : présentation des candidats, élection, puis passation en cas de mort.
      • Voleur : après son choix, tous les joueurs reprennent connaissance de leur rôle.
      • Renard : une fenêtre te demande ta réponse (Oui / Non).
      • Le Jour se lève : annonce des morts, passation du Maire, chasseur, puis débat et vote du village (égalité = Pierre-feuille-ciseaux).

      3. Autres outils

      • ⚡ Effets Sonores : sons d'ambiance (fermez les yeux, place au vote…).
      • Le tableau des joueurs permet de suivre rôles, morts, couples et maire.
      • Le rôle d'un joueur se masque automatiquement en cours de partie et peut être rouvert à tout moment.

      4. En cas de souci

      • Pas de son sur l'écran secondaire : clique une fois dessus.
      • Un joueur déconnecté : il recharge sa page et se reconnecte avec le même prénom.
      • Après une mise à jour : Ctrl+F5 et vérifie le numéro de version en bas de page.
